# 合规与证据边界

## 当前能够证明的事实

- 两个 MCP 服务器可以注册并通过 SDK 的 `InMemoryTransport` 调用。
- DSH overlay 可以同时声明两个 MCP server 和两个 filesystem skill provider。
- 固定的高中物理 fixture 可以完成学生—教师 8 步演示。
- Zod 契约拒绝真实姓名替代匿名演示 ID，并阻止来源/AI 标识不完整的发布审核请求。

## 当前不能证明的事实

- 未调用真实大模型、联网检索、ComfyUI 或 3D 工具。
- 未连接真实前端、账号、学校数据库、课堂设备或监护人授权系统。
- 未进行真实课堂试点，不能声称提升成绩、降低教师工时或达到商业可用性。

## 产品化前的硬门槛

- 完成未成年人敏感个人信息处理规则、监护人同意、查询/更正/删除/撤回机制。
- 分离身份数据、学习内容、教学资源和模型训练数据。
- 核验教材、课件、图片、音乐、视频、肖像和第三方工作流授权。
- 为生成内容添加适用的显式/隐式标识，并记录来源、模型版本、工作流版本、成本和教师审核。
- 禁止作业代做、考试作弊、绕过学校管理或自动作出关键教学评价。
